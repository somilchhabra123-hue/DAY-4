Diagnosis: Checking facts, unsupported claims, passenger instructions, tone and length.
Six-stage refinement: Correct facts → remove unsupported information → add instructions → improve tone → control length → add verification safeguard.

Targeted prompting: Compares “Make it better” with a specific correction prompt.

Own iteration relay: Student chooses an aviation scenario and documents the complete improvement process.
Peer review: Checks accuracy, clarity, tone, verification and privacy.
